# Ligne 4

Appli de relais de natation (Android, Windows, Web) : voir https://lab.codexmental.com/#/p/ligne4

- `latest.json` est produit par `publier.ps1` (dossier `dist\<version>\`), avec l'empreinte SHA-256 de chaque fichier.
- Les fichiers sont dans la release GitHub `ligne4-v<version>` de ce dépôt.
- `download_url` et `sha256` désignent l'APK arm64 (téléphones récents) ; la liste `downloads` donne toutes les versions
  (`android`, `windows`, `windows-portable`) ; `web_url` ouvre la version Web.
